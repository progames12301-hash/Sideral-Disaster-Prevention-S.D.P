# S.D.P network measurements

`latest-seedlink-probe.json` is generated by GitHub Actions every six hours and after changes to the SeedLink ingestion code.

A station is marked `eewCandidate` only when the probe receives at least three packets and its measured p95 data latency is at or below the configured S.D.P threshold (8 seconds by default). This is a transport/data-quality measurement, not a guarantee of warning lead time or an official alert capability.
